# Bernini-R 编辑模型蒸馏：分阶段分析

## 0. 总览：编辑蒸馏与生成蒸馏的根本差别

| 维度 | 生成蒸馏 (T2V) | 编辑蒸馏 (Bernini) |
|---|---|---|
| 条件 | 全局文本 | 文本 + **逐帧对齐的源视频 latent 流** + 参考图 |
| token 布局 | 仅噪声目标 | `[源/参考 cond \| (clean 历史) \| 噪声目标]`（in-context 拼接） |
| 位置编码 | 标准 3D RoPE | + **source_id RoPE**（噪声=0、源=1、参考=2…；源为空时退化为原模型） |
| 注意力 | 目标块级因果 | 源/参考前缀**全可见** + 目标块级因果 |
| Teacher 引导 | 单尺度 CFG | **Bernini 链式多条件引导**（rv2v 4 次 / v2v_apg 2 次前向） |
| 数据 | DMD 全程 data-free | Stage1/2 需 GT 编辑对；Stage3 对 target data-free |
| 头号退化 | 一般质量下降 | **"照抄源、不执行指令"** + 运动动态退化 |

三个核心机制（实现于 `models/causal_edit_model.py`）：

1. **条件拼接**：源/参考 patch-embed 后拼到噪声目标前作前缀。
2. **source_id RoPE**：每条流一个复数乘子区分"源/参考/目标"，目标 `id=0` 时为单位元 → 无源时与原模型数值一致。
3. **编辑 mask**：条件前缀互相全可见；目标对全部条件可见 + 对自身历史块级因果。

## 1. Stage 1 — AR Teacher（自回归 teacher-forcing 扩散）

实现：`models/edit_diffusion.py` · 入口：`train_edit_ar.py` · 配置：`configs/causvid_edit_ar_1.3b.yaml`

### 目标
把双向 Bernini 权重改造成**因果、多步**的编辑扩散模型。用 teacher forcing（喂干净目标历史），学"在源条件下、基于历史帧预测当前帧"。产物 `ar_diffusion.pt` 作为 Stage 2 的初始化。损失：flow-matching MSE（带 timestep 权重）。

### 生成 vs 编辑差别
- **数据**：生成用 GT 真实视频；编辑**必须有 (source, target) 配对，且 target 是"编辑后"视频**（需先用离线 Bernini 跑伪标签）。→ 这一步**不是 data-free**。
- **条件**：多了逐帧源 / 参考，透传进 `conditional_dict`。
- **序列**：TF mask 是 `[cond | clean | noisy]` 三段，源逐帧对齐时 ≈ **3× 目标 token 数**，比推理还长。

### 可能的问题
- **target 质量即上限**：离线 Bernini 伪标签的好坏直接决定天花板。
- **对齐要求严格**：source / target / ref 必须同帧数、分辨率、同一 VAE 归一化；时间轴逐帧对齐，否则 source_id RoPE 错乱。
- **"照抄源"已可能出现**：未改动区 MSE≈0，模型可能学成 copy。需监控编辑区 `x0_pred` 是否真偏离源。
- **train/test mismatch（与 T2V 共有，非编辑特有）**：喂干净 GT 历史、推理是自生成历史。这是 Causal-Forcing 通用现象，Stage 3 的 self-forcing rollout 本就为闭合它而设计；编辑因有逐帧源锚点反而可能更轻。可选开 `noise_augmentation_max_timestep` 进一步缓解。
- **粒度锁定**：`num_frame_per_block`（framewise=1 / chunkwise=3）一旦定，全链路不可改。
- 超参：`lr=1e-5`、grad clip 10、EMA 默认关；建议 ≥2K step。

## 2. Stage 2 — 因果一致性蒸馏 CF++

实现：`models/edit_consistency.py` · 入口：`train_edit_cd.py` · 配置：`configs/causvid_edit_cd_1.3b.yaml`

### 目标
把 Stage 1 多步 AR 模型蒸成**少步（4-step）因果**模型，作为 Stage 3 DMD 的"理论正确初始化"。免 ODE 配对数据，仅用 GT 编辑对。三模型：generator（可训）、generator_ema（一致性目标，**即交付物**）、teacher（Stage 1，冻结）。损失：student 在 `t` 的 x0 ≈ EMA 在 `t_next` 的 x0（teacher 走一步 CFG 得 `t_next`）。

### 生成 vs 编辑差别
- teacher 的一步 CFG 里，uncond 分支**保留源/参考**，CFG 只作用于**文本**（cond text vs negative prompt）。
- 全程仍 teacher-forcing 干净历史 + 透传源条件。

### 可能的问题
- **⚠ teacher 方向与 Stage 3 不一致**：Stage 2 = 文本-CFG（+源），Stage 3 = 链式引导 → 两阶段目标分布不同，初始化可能被 DMD 部分推翻（编辑链路的结构性缝隙）。
- **只压步数、不造编辑能力**：忠实继承 Stage 1 行为；若 Stage 1 照抄源，这里只会压成少步版的照抄源。
- **一致性沿扩散轴、非时间轴**：教的是少步去噪，**不教 AR rollout 稳定性**（后者只靠 mask + TF）。
- **naive CD 误差累积**：相邻小步一致 ≠ 4 次大跳后无累积误差。
- **EMA 即交付物**：`ema_weight=0.95` 偏快、`ema_start_step=0`，目标移动快易抖；要直接监控 EMA 输出质量。
- **显存重**：每 step 在长 TF 序列上 4 次前向（teacher cond/uncond + generator + ema），3×1.3B 常驻。
- 超参：`discrete_cd_N=48`、`lr=2e-6`；建议 ≥3K step。

## 3. Stage 3 — 非对称 DMD（最终模型）

实现：`models/edit_dmd.py` · 入口：`train_edit.py` · 配置：`configs/causvid_edit_1.3b.yaml`

### 目标
在 Stage 2 初始化上做非对称 DMD，得到最终少步（1/2/4-step）因果编辑学生。三模型：generator（因果学生，可训）、fake_score（双向 critic，可训）、real_score（Bernini 链式引导 teacher，冻结）。学生 dense 截断 rollout 出整段，梯度 `grad = pred_fake − pred_real`。**对 target data-free**（只用 source + prompt）。

### 生成 vs 编辑差别
- real_score 从"单 CFG"变成"链式多条件引导"（`eps_0 / eps_v / eps_vi / eps_vti` 级联）。
- rollout 透传源、**不喂干净历史**（首次无 teacher forcing）。

### 可能的问题
- **⚠ 编辑信号 100% 来自链式引导**：未改动区 teacher≈学生≈copy → 梯度≈0 → 无力推动编辑。引导一弱就照抄源。**这是最脆弱处。**
- **引导尺度失配**：`omega_*` 来自双向 50 步 Bernini，少步+单点场景大概率过/欠引导；teacher 分数跨 timestep 尺度剧烈波动（已观测），经 normalizer 污染梯度方向。**推理不可再调，必须训练前 sweep。**
- **非对称：critic 跟不上即废**：`pred_fake` 是普通条件分数，`pred_real` 是引导分数；`lr_critic=4e-7` 极小、更新比 5:1，critic 滞后则梯度失真。
- **exposure bias（与 T2V 共有，且本就由 DMD 阶段处理）**：Stage1/2 干净历史、Stage3 自生成历史。这正是 self-forcing rollout 设计要闭合的 gap；编辑有源锚点，通常比纯 T2V 更稳，不是编辑特有风险。
- **过训 → 动态退化 + 照抄源叠加**：源已提供运动，学生倾向冻结运动。须 ≤1K step（bs64）+ 好初始化，盯 `samples/step_*.mp4`。
- **timestep 窗口未对齐**：`ts_schedule=false`，打分 t 近全程均匀采，梯度更噪。
- **bf16 数值**：链式差分 ×大 omega 易溢出；normalizer 近除零靠 `nan_to_num` 兜底（已踩过 NaN）。
- **显存最紧**：3×1.3B + T5 + VAE 常驻，rollout 多次前向 + teacher 2~4 次；换 rv2v 或加帧易爆。
- **EMA 即交付物**：`ema_weight=0.99`，推理务必用 EMA 权重。

## 4. 跨阶段系统性风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| TF → no-TF（**T2V/编辑共有，非编辑特有**） | Stage1/2 干净历史 → Stage3 自生成历史；Self-Forcing 的 DMD 阶段本就为闭合它而设计，编辑因有源锚点反而更稳 | （通用技巧）Stage1/2 可开历史噪声增强 |
| **teacher 方向不一致** | Stage2 文本-CFG vs Stage3 链式引导，目标分布不同 | 评估初始化是否被 DMD 推翻；必要时统一引导口径 |
| **"照抄源"贯穿全程** | Stage3 未改区零梯度最致命 | 全程把"输出 vs 源差异度"作为一级监控指标 |
| **引导强度不可事后调** | 已蒸进权重 | omega / guidance_scale 训练前定好并 sweep |

## 5. 一句话速记

- **Stage 1**：造因果多步编辑模型；难在**伪标签质量 + 对齐 + 初现照抄源**。
- **Stage 2**：压成少步初始化；难在**只压步数不造能力 + teacher 方向与 S3 不一致 + EMA 即交付**。
- **Stage 3**：DMD 出最终模型；难在**data-free 下编辑全靠链式引导 + 照抄源/动态退化 + 数值/显存**。（exposure bias 与 T2V 共有，已由 DMD 阶段处理，非编辑特有）

## 附录 A：监控指标（每阶段该盯什么）

| 阶段 | 一级指标（必盯） | 二级指标 | 健康信号 / 危险信号 |
|---|---|---|---|
| **Stage 1 AR** | flow MSE loss、grad_norm | **编辑区 x0_pred vs 源的差异度**、样本可视化 | loss 平稳下降；grad_norm 稳定（clip=10 内）。⚠ loss 降但输出=源 → 照抄源 |
| **Stage 2 CD** | consistency loss、**EMA 输出质量** | grad_norm、t/t_next 分布 | loss 下降且 EMA 4-step 出图清晰。⚠ loss 抖 / EMA 崩 → EMA 过快或初始化差 |
| **Stage 3 DMD** | gen_loss、crit_loss、**dmdtrain_gradient_norm** | 样本 mp4（每 save_every）、运动幅度 | gen/crit 互相拉锯但不发散。⚠ gen_loss→0 且画面冻结 → 动态退化/照抄源 |

**贯穿全程的一级指标：`输出 vs 源 的差异度`**（在"应改区"要大、"不应改区"要小）。这是编辑特有、比 loss 更能反映"是否真在编辑"的指标。

**数值健康**：每阶段都监控 `pred/x0 是否 finite`、`grad_norm 是否突刺`；Stage 3 额外盯 teacher `pred_real absmax` 跨 timestep 是否剧烈波动。

## 附录 B：推荐超参起点（取自仓库 config）

### Stage 1 — AR Teacher
| 参数 | 起点 | 说明 / 调整方向 |
|---|---|---|
| `lr` | `1e-5` | 回归训练，可稳 |
| `betas` | `(0.9, 0.999)` | 标准 |
| `num_frame_per_block` | `1` | **全链路锁定**，不可改 |
| `timestep_shift` | `5.0` | 跟随 Bernini |
| `teacher_forcing` | `true` | — |
| `noise_augmentation_max_timestep` | `0` → **建议开 ~50–100** | 缓解 Stage 3 的 TF→no-TF 断层 |
| `ema_weight` | `0.0`（关） | Stage 1 可不开 |
| grad clip / batch | `10` / `1` | 显存所限 |
| 步数 | **≥2K**（5–10K 更佳） | 数据少防过拟合 |

### Stage 2 — Causal CD（CF++）
| 参数 | 起点 | 说明 / 调整方向 |
|---|---|---|
| `lr` | `2e-6` | 小步精修 |
| `betas` | `(0.0, 0.999)` | 蒸馏惯例 |
| `discrete_cd_N` | `48` | 一致性网格 |
| `guidance_scale` | `3.0` | **与 Stage 3 引导口径尽量协调** |
| `ema_weight` | `0.95` → **可试 0.99** | 0.95 偏快、目标易抖 |
| `ema_start_step` | `0` | — |
| `generator_ckpt` | Stage 1 产物 | 必填 |
| 步数 | **≥3K**（5–10K 更佳） | — |
| 交付物 | `generator_ema` | → Stage 3 的 `generator_ckpt` |

### Stage 3 — 非对称 DMD
| 参数 | 起点 | 说明 / 调整方向 |
|---|---|---|
| `lr` / `lr_critic` | `2e-6` / `4e-7` | **critic 太小则滞后**，可小幅上调观察 |
| `betas` | `(0.0, 0.999)` | — |
| `dfake_gen_update_ratio` | `5` | critic 跟不上可加大 |
| `denoising_step_list` | `[1000,750,500,250]` | 4-step；1/2-step 用首块 4 步技术 |
| `warp_denoising_step` | `true` | — |
| `guidance_mode` | `v2v_apg`（2 forwards） | 省显存；需更强编辑可试 `rv2v`(4) |
| `omega_v / omega_i / omega_ti` | `1.25 / 4.5 / 4.0` | **头号待调超参，训练前 sweep；推理不可改** |
| `ts_schedule` | `false` → **可试 true** | 对齐 exit step，降梯度噪声 |
| `ema_weight` / `ema_start_step` | `0.99` / `200` | 推理务必用 EMA |
| 步数 | **≤1K（bs64）** | 过训→动态退化；小 bs 可适当增加 |

## 附录 C：上手排查清单（按执行顺序）

### 数据 / 准备
- [ ] 离线 Bernini 已为每条 (source, prompt) 跑出 **edited target** mp4。
- [ ] `gen_edit_targets.py` 编码后，`index.json` 中 `source/target/refs` 路径正确。
- [ ] source / target / ref **同帧数、同分辨率、同 VAE 归一化**；时间轴逐帧对齐。
- [ ] `image_or_video_shape` 与实际 latent 形状一致（如 `[1,21,16,60,104]`）。

### Stage 1
- [ ] `train_edit_ar.py` 未因缺 `target_latent` 报错（说明 manifest 带 target、`load_target=True`）。
- [ ] loss 平稳下降；样本里**编辑区确有变化**（不是 copy 源）。
- [ ] （建议）开历史噪声增强后再训一版对比鲁棒性。

### Stage 2
- [ ] `generator_ckpt` 指向 Stage 1 实际 checkpoint 路径。
- [ ] 监控 **EMA 输出**（交付物）4-step 出图质量，而非只看 loss。
- [ ] 确认 EMA 不抖（必要时 0.95→0.99）。

### Stage 3
- [ ] `generator_ckpt` 指向 Stage 2 的 `generator_ema`。
- [ ] 先小数据跑几百 step：gen/crit loss 健康、无 NaN 复发、`samples/*.mp4` 真在编辑。
- [ ] 盯**运动是否还活**（防冻结）+ **未改区是否稳定**（防乱改）。
- [ ] sweep `omega_*`（先固定 v2v_apg，调 `omega_ti`）。
- [ ] 控制步数 ≤1K；推理加载 **EMA** 权重。

### 显存 / 工程
- [ ] 三阶段均 `gradient_checkpointing: true`、`batch_size: 1`。
- [ ] 上真实全长帧前，先用 `EDIT_MAX_LAT_FRAMES` 截断验证流程。
- [ ] Stage 3 若显存吃紧：保持 `v2v_apg`（2 forwards），勿轻易切 `rv2v`(4)。
- [ ] bf16 出 NaN：先查 target latent finite，再查 teacher 差分溢出 / normalizer 近除零。

## 附录 D：三大退化的快速判别

| 现象 | 最可能原因 | 首选对策 |
|---|---|---|
| 输出≈源、指令没执行 | 引导太弱 / 未改区零梯度 | 调大 `omega_ti`、检查 teacher 引导、加编辑区监控 |
| 画面冻结、运动消失 | DMD 过训 / 抄源运动 | 减步数、强化 Stage 2 初始化、`ts_schedule=true` |
| 后段帧崩坏、漂移 | AR 累积误差（T2V/编辑共有；编辑有源锚点通常更轻） | 检查块级因果 mask；可选历史噪声增强 |
| 训练 NaN | bf16 差分溢出 / 除零 | 查 finite、降 omega、稳住 normalizer |
